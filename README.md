# CGCMES.cpp

---------------------------------------------------------------------------------------------------------------

A C++ console-based program that allows users to create and manage group members, including assigned tasks and their statuses; create important notes and reminders; and view contribution metrics and each member's rank based on the number of tasks and their progress status. The program uses vectors (dynamic arrays) to store member, task, and note lists, and structures (struct Member, struct Task, and struct Note) to organize member, task, and note data. All of the data input by the user is handled through file handling (.txt files) to save and retrieve records of members, tasks, and notes across program runs.
